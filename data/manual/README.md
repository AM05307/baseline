# data/manual/

`scripts/verify_outlier.py`가 읽는 폴더다. KRX 정보데이터시스템(data.krx.co.kr)
등에서 직접 받은 **공식 종가 CSV**를 여기 넣으면, 이 프로젝트 DB(yfinance
기반)의 값과 대조해볼 수 있다 — 자동으로 고치지는 않는다, 비교 결과만 보여준다.

## 기대하는 CSV 형식

열 이름(대소문자 무시, 아래 후보 중 하나씩만 있으면 됨):

- 날짜: `date` | `일자` | `날짜`
- 종가: `close` | `종가` (천단위 구분 쉼표가 있어도 됨, 예: `184,100`)

```csv
date,close
2001-11-09,138000
2001-11-12,182000
```

다른 열(시가/고가/저가/거래량 등)이 있어도 무시되니 그대로 둬도 된다.

## 파일 이름

아무 이름이나 괜찮다(`verify_outlier.py`가 폴더의 모든 `*.csv`를 훑어서
필요한 날짜가 있는 파일을 찾는다). 종목 하나당 파일 하나를 권장한다.

## 이 폴더는 git에 커밋되지 않는다

`.gitignore`에 `data/manual/*.csv`가 있다 — KRX 원본 데이터를 그대로
커밋하지 않기 위해서다. 이 README만 git에 남는다.
