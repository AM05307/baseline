# 위험 점수 신호를 069500(KODEX 200)에 적용할 때 — 현재 처리와 제안

작성: 2026-10-19 · **제안 문서. 섀도 대상만 069500으로 바꿨고, 신호 계산은 바꾸지 않았다.**

섀도 실행기(`config/executor.yaml` `shadow.ticker`)는 이제 069500을 사고판다. 하지만 위험 점수를 만드는 신호값(`signal_values`)은
`scripts/compute_signals.py`가 **000660 기준으로 계산한 것 하나뿐**이다. 그래서 지금 섀도는 "000660·거시 신호로 정한 단계를
069500에 적용"하는 상태다. 아래 표는 신호마다 그것이 069500에 맞는지와 제안이다.

## 구현할 때의 방법 (제안)

1. `signal_values`에 대상 종목 열이 없다. 가장 작은 변경은 **대상 시세로 계산하는 신호를 섀도·백테스트 안에서 즉석 계산**하는 것이다
   (`analysis/signals.py`의 함수는 시세 Series만 받으므로 그대로 쓸 수 있다). DB 스키마는 바꾸지 않는다.
2. 대상별 제외·대체 목록은 설정 파일 한 곳(`config/signal_groups.yaml`의 대상별 섹션)에 두고, 섀도·what_if·비교 백테스트가 같은 목록을 읽게 한다.
3. 대체하면 R3의 과거 분포가 바뀌므로 **백분위 기준점도 대상별로 다시 정해야 한다**(같은 기준 기간 규칙으로, 검증 기간 결과를 보고 고르지 않음).

국장/미장 비교 백테스트(`scripts/market_compare.py`)는 이 문서의 "안 맞음" 신호를 **제외**하는 쪽으로만 구현했다(대체는 하지 않음).
